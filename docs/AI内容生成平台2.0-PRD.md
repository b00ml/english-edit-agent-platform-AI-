## 2. 需求背景

### 2.1 业务背景

传统英语教研内容生产依赖人工，存在生产周期长、竞品题型单一、成本高三类痛点。1.0 已基于 Dify + Llama3 + LoRA 落地 AI 内容生成 Agent，将生产周期从数周压缩到数小时，支撑 5 万+ 内容产出，结构化符合率提升至 99%+。

### 2.2 当前问题

1.0 本质是「脚本 + Prompt」的半自动化工具链，存在以下短板：

- **无质量闭环**：以人工抽检为主，无法规模化保障输出质量，劣质内容可能进入内容库。
- **题型扩展靠改代码/Prompt**：新增题型成本高，难以规模化。
- **无可观测性**：单次生成不可追踪、不可复盘，问题根因难定位。
- **无可编排生产线**：选题→出题→质检→改版→入库→发布未形成自动化闭环。
- **知识依据弱**：未接入教材、课标、真题库，内容缺少事实依据支撑。

### 2.3 需求依据

- 1.0 落地经验与数据（生产周期、内容量、符合率、降本比例）。
- 技术演进：Agent/Workflow、结构化输出、RAG、LLM-as-judge、可观测性、模型成本下降均趋于成熟。
- 具体基线目标值见「15. 数据指标」，多数待确认。

## 3. 产品目标

**产品定位（已确认）**：内部先行，后对外。首期作为公司内部教研团队的生产工具，在架构上预留对外商业化能力（多租户、权限、计费、内容安全），为后续对外化演进留出空间。

- 将内容生产从「单点生成」升级为「可编排、可评估、可持续优化」的 AI 原生生产线。
- 建立「自动质检 + 人工抽检」质量闭环，降低劣质内容入库率。
- 题型以配置化模板接入，新增题型不改代码。
- 全链路可观测、可回放，提供成本核算，支撑规模化生产。
- 首期落地「单选 + 完形 + 阅读理解」三类题型，验证最小闭环（P0）。

- 不做多模态题型（听力、口语、图文阅读）的首期实现，仅预留扩展点（见 9.10）。【已确认】

- 不做自有基础大模型训练，复用开源/商用模型并微调。

## 6. 核心业务场景

### 场景 1：批量出卷

- 使用角色：教研员
- 触发时机：教研员需要按知识点、难度批量产出某类题目
- 当前问题：人工逐题编制成本高、周期长
- 目标结果：一次性生成一批符合 Schema、通过质检的题目并入库

### 场景 2：质量保障

- 使用角色：质检员 / 系统
- 触发时机：题目生成完成、待质检
- 当前问题：人工抽检难以覆盖全部内容
- 目标结果：系统自动按质量规则打分，低分自动改版或驳回，人工仅抽检

### 场景 3：问题复盘

- 使用角色：管理员 / 教研员
- 触发时机：发现某批内容质量异常
- 当前问题：无法定位生成链路问题
- 目标结果：通过 Trace 回放单次生成，定位 prompt 版本、模型、输入输出与质检分

| 对象 | 定义 | 关键字段 | 状态 | 归属 |

## 8. 业务流程

### 8.1 主流程

1. 教研员在「生成」页选择题型模板、填写输入参数（知识点、难度、数量）、发起生成。
2. 系统创建生成任务，进入任务队列。
3. 系统按模型路由配置分发到对应模型推理，调用结构化输出引擎生成内容。
4. 系统对每条内容执行 Schema 校验；校验失败进入重试路由。
5. 系统对校验收过的内容执行自动质检（LLM-as-judge 按质检规则打分）。
6. 质检通过的内容入库；低分内容进入改版流程（迭代重试）。
7. 入库内容经人工抽检（可选）后发布。
8. 全链路写入 Trace 日志（prompt 版本、模型、输入输出、质检分、耗时、成本）。

### 8.2 分支流程

- **Schema 校验失败**：进入重试路由，最多重试 3 次，仍失败则标记该条失败。
- **质检低分改版**：触发改版迭代，最多 3 次，仍不合格则驳回。
- **人工驳回**：驳回后内容进入废弃/待改版状态。

### 8.3 异常流程

- 模型接口超时/失败：任务重试或降级到备用模型。
- 任务中断重启：断点续跑，不重复生成已完成条目。
- 重复提交：按「题型+输入参数」哈希去重，避免重复生成。

## 9. 功能需求

### 9.1 题型模板管理

#### 功能目标
以配置化方式管理题型，新增题型不改代码。

#### 使用角色
管理员

#### 使用入口
前端工作台「题型模板」页

#### 前置条件
- 管理员登录

#### 功能规则
规则 1：创建/编辑题型模板

- 适用对象：题型模板
- 前置条件：管理员有模板管理权限
- 触发条件：管理员在模板页新建或编辑
- 系统动作：校验输入 Schema、输出 Schema、质检规则格式合法后保存为新版本
- 状态变化：草稿 → 已启用（启用后用于生成）
- 结果反馈：保存成功提示
- 例外情况：Schema 非法时提示错误、不允许保存；已启用模板不可直接编辑，需基于新版本修改

#### 页面与交互
- 页面结构：模板列表 + 模板编辑表单
- 展示内容：模板名称、题型、状态、版本、启用时间
- 操作按钮：新建、编辑、启用/停用、查看版本
- 空状态：无模板时提示「去创建」
- 错误状态：Schema 校验失败提示具体字段

#### 验收标准
- Given：管理员已登录且有模板权限，输入合法 Schema
- When：点击保存并启用
- Then：模板进入「已启用」状态，可在生成页选择

### 9.2 生成任务管理

#### 功能目标
支持批量生成任务的创建、执行、监控与断点续跑。

#### 使用角色
教研员、管理员（查看全部，范围待确认）

#### 使用入口
前端工作台「生成任务」页

#### 前置条件
- 至少存在一个已启用的题型模板及对应模型路由配置

#### 功能规则
规则 1：发起批量生成

- 适用对象：生成任务
- 前置条件：教研员已登录，所选模板已启用
- 触发条件：教研员填写输入参数并提交
- 系统动作：创建生成任务并入队；按路由配置选择模型；逐条生成
- 状态变化：待执行 → 执行中 → 成功/部分成功/失败
- 结果反馈：任务进入执行中，可查看进度
- 例外情况：输入参数非法（如数量超上限）时拒绝提交并提示

规则 2：断点续跑

- 适用对象：生成任务
- 前置条件：任务因中断失败
- 触发条件：重新启动该任务
- 系统动作：跳过已完成条目，仅生成未完成条目
- 结果反馈：任务继续执行，不重复生成已完成条目

#### 页面与交互
- 展示内容：任务列表（ID、题型、数量、状态、进度、耗时、成本）
- 筛选条件：状态、题型、时间范围
- 操作按钮：发起生成、重试、查看详情、取消
- 空状态：无任务时提示
- 加载状态：执行中显示进度条

#### 验收标准
- Given：任务因中断失败，存在部分已完成条目
- When：重新启动任务
- Then：仅生成未完成条目，已完成条目不重复生成

### 9.3 结构化输出引擎

#### 功能目标
保证生成结果符合题型 Schema，结构化符合率趋近 100%。

#### 使用角色
系统内部组件

#### 功能规则
规则 1：Schema 校验与重试

- 适用对象：内容条目
- 前置条件：模型返回生成结果
- 触发条件：结果返回后系统校验
- 系统动作：按输出 Schema 校验字段、类型、枚举值；校验失败走重试路由（默认最大重试次数 N=3，可配置）
- 状态变化：校验中 → 已通过 / 校验失败(重试)
- 结果反馈：通过则进入质检，失败则记录重试
- 例外情况：重试耗尽仍失败 → 该条标记为失败

#### 验收标准
- Given：模型返回不符合 Schema 的结果
- When：系统执行校验
- Then：结果不进入质检，进入重试路由

### 9.4 自动质检（LLM-as-judge）

#### 功能目标
按题型质检规则对生成内容自动打分，替代人工全量抽检。

#### 使用角色
系统内部组件

#### 功能规则
规则 1：自动打分

- 适用对象：内容条目
- 前置条件：内容通过 Schema 校验
- 触发条件：系统对每条内容执行质检
- 系统动作：按题型模板的质检规则（如知识点匹配、难度匹配、选项干扰性、无歧义）逐维度评分，汇总总分（默认总分 0-100，阈值 70 分，可配置）
- 状态变化：已通过校验 → 已通过质检 / 待改版
- 结果反馈：评分写入质检记录
- 例外情况：评分低于阈值（默认 70）→ 进入改版流程

#### 验收标准
- Given：内容通过 Schema 校验，质检规则已配置
- When：系统执行自动质检
- Then：生成质检记录，含各维度分与总分

### 9.5 改版流程

#### 功能目标
对低分内容自动迭代优化，达到质量要求。

#### 使用角色
系统内部组件

#### 功能规则
规则 1：低分改版

- 适用对象：内容条目
- 前置条件：内容质检分低于阈值
- 触发条件：系统触发改版
- 系统动作：携带上一轮质检反馈重新生成，最多迭代 M 次（默认 M=3，可配置）
- 状态变化：待改版 → 改版中 → 已通过质检 / 已驳回
- 结果反馈：达标则入库，达到最大迭代仍不达标则驳回
- 例外情况：迭代次数耗尽 → 标记驳回

#### 验收标准
- Given：内容质检分低于阈值
- When：系统执行改版
- Then：携带质检反馈重新生成；达到最大迭代仍不达标则驳回

### 9.6 人工抽检与标注

#### 功能目标
人工抽检已通过内容，回传评估结果，校准质检标准。

#### 使用角色
质检员

#### 使用入口
前端工作台「质检」页

#### 功能规则
规则 1：人工抽检

- 适用对象：内容条目
- 前置条件：内容已通过自动质检并入库
- 触发条件：抽检任务分配给质检员 / 质检员主动抽检
- 系统动作：质检员查看内容并标注通过/驳回及原因
- 状态变化：已入库 → 已发布 / 已驳回
- 结果反馈：标注结果回传，作为质检标准校准依据
- 例外情况：默认抽检比例 10%（个人场景可由开发者手工抽查，可配置）

#### 页面与交互
- 展示内容：待抽检内容、质检分、维度分
- 操作按钮：通过、驳回（含原因）、跳过
- 空状态：无待抽检内容

#### 验收标准
- Given：内容已通过自动质检并入库，被分配到质检任务
- When：质检员标注「驳回」并填写原因
- Then：内容状态变为「已驳回」，标注结果记录在案

### 9.7 内容库与发布

#### 功能目标
管理已通过质检的内容，支持检索、预览与发布。

#### 使用角色
教研员、查看者

#### 使用入口
前端工作台「内容库」

#### 功能规则
规则 1：入库与发布

- 适用对象：内容条目
- 前置条件：内容通过自动质检（人工抽检为可选项）
- 触发条件：内容入库后，可由教研员发布
- 系统动作：发布后内容对查看者可见
- 状态变化：已入库 → 已发布
- 结果反馈：可检索到已发布内容
- 例外情况：未通过质检内容不可入库、不可发布

#### 页面与交互
- 展示内容：内容列表（题型、知识点、难度、质检分、状态）
- 筛选/搜索：按题型、知识点、难度、状态、质检分
- 操作按钮：预览、发布/下架、查看质检记录
- 空状态：无内容时提示

#### 验收标准
- Given：内容未通过质检
- When：教研员尝试发布
- Then：发布被阻止，内容不进内容库

### 9.8 可观测性（Trace 回放）

#### 功能目标
记录每次生成的完整链路，支持问题复盘与成本核算。

#### 使用角色
管理员、教研员（范围待确认）

#### 使用入口
前端工作台「Trace」页

#### 功能规则
规则 1：生成链路记录

- 适用对象：内容条目 / 生成任务
- 前置条件：系统执行生成
- 触发条件：任意一次生成
- 系统动作：记录 prompt 版本、输入参数、模型、输出、质检分、耗时、成本
- 结果反馈：可在 Trace 页检索并回放单次生成
- 例外情况：记录缺失时标记「无 Trace」

#### 页面与交互
- 展示内容：链路节点（输入→生成→校验→质检→结果）、各节点耗时/成本
- 操作按钮：回放、筛选、导出（待确认）

#### 验收标准
- Given：某一内容生成完成
- When：在 Trace 页检索该内容
- Then：可查看到完整链路节点、质检分、耗时与成本

### 9.9 模型路由与成本核算

#### 功能目标
按题型/成本/质量差异路由到合适模型，并提供成本核算。

#### 使用角色
管理员（配置）、查看者（成本报表，范围待确认）

#### 功能规则
规则 1：模型路由配置

- 适用对象：模型路由配置
- 前置条件：管理员可访问模型配置
- 触发条件：管理员配置某题型默认/备用模型
- 系统动作：生成时按题型选择对应模型，接口失败降级到备用模型
- 状态变化：已停用 → 已启用
- 结果反馈：生成任务按配置路由
- 例外情况：无路由配置时使用全局默认模型（建议方案）

#### 验收标准
- Given：某题型配置了模型 A 为默认、模型 B 为备用
- When：模型 A 接口失败
- Then：该题型生成降级使用模型 B，并在 Trace 中记录

## 10. 状态流转

### 10.1 状态定义

## 14. 异常与边界情况

| 场景 | 触发条件 | 系统处理 | 用户反馈 |
|---|---|---|---|
| Schema校验失败 | 输出不符合Schema | 进入重试路由，最大3次 | Trace标记重试 |
| 质检低分 | 总分低于70 | 进入改版流程 | Trace标记改版 |
| 改版耗尽 | 迭代达3次仍低分 | 标记驳回 | 可查看原因 |
| 模型接口失败 | 默认模型超时/报错 | 降级备用模型或重试 | Trace标记降级 |
| 任务中断 | 进程异常终止 | 断点续跑 | 重启按钮 |
| 重复提交 | 相同输入重复发起 | 去重（题型+输入参数哈希，默认开启） | 提示已存在 |
| 无路由配置 | 题型无路由 | 使用全局默认模型 | Trace标记默认 |
| 数量超上限 | 输入数量超限制 | 拒绝提交 | 提示超限 |
| Trace缺失 | 链路记录缺失 | 标记「无Trace」 | 展示提示 |

## 16. 验收标准汇总

### 16.1 正常流程

- Given：已启用题型模板与模型路由配置，教研员已登录
- When：教研员发起批量生成
- Then：任务执行并生成符合 Schema 的内容，通过自动质检后入库

### 16.2 异常流程

- Given：内容输出不符合 Schema
- When：系统执行校验
- Then：进入重试路由，不进入质检；重试耗尽标记失败

### 16.3 权限和数据

- Given：查看者角色
- When：访问内容库
- Then：仅可见已发布内容，未发布内容不可见
