## 推送顺序

1. 创建 GitHub 空仓库，不自动生成 README、License 或 .gitignore。
2. 本地创建 open-source-prep 分支。
3. 按公开范围白名单暂存，运行 git diff --cached --check。
4. 推送准备分支，检查 README、Actions、依赖和密钥扫描。
5. 人工确认后合并到 main，再创建第一个 Release。
